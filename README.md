# 2deHandsSite

Barebones React + TypeScript project using Vite and pnpm. The app intentionally renders a blank page, with no demo content or styles.

```sh
pnpm install
pnpm dev
```

Edit `src/App.tsx` to start building.

```sh
pnpm build    # Type-check and create a production build
pnpm preview  # Preview the production build
```
